# NodoAssist Feishu/Lark

Official NodoAssist channel plugin for Feishu and Lark workplace chats. Community maintained by @m1heng.

Install from NodoAssist:

```bash
nodoassist plugin add @nodoassist/feishu
```

Configure the Feishu/Lark app credentials in NodoAssist, then connect the plugin to the chats where agents should receive and send messages.
