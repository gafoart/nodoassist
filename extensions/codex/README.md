# NodoAssist Codex

Official NodoAssist provider and harness plugin for OpenAI Codex app-server integration. It exposes the Codex-managed GPT model catalog and the Codex runtime surfaces used by NodoAssist agents.

Install from NodoAssist:

```bash
nodoassist plugin add @nodoassist/codex
```

Use this plugin when you want NodoAssist to run Codex-backed model turns, media understanding, and prompt overlays through the Codex app-server harness.
