# Vercel AI Gateway NodoAssist provider

Official NodoAssist provider plugin for Vercel AI Gateway.

## Install

```sh
nodoassist plugins install @nodoassist/vercel-ai-gateway-provider
```

## Docs

See `docs/providers/vercel-ai-gateway.md` in the NodoAssist repository, or the published docs at `https://docs.openclaw.ai/providers/vercel-ai-gateway`.
